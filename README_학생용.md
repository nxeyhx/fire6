# 07단계 · 실시간 시뮬레이션과 ESP32 실제 구현

## 이번 수정의 핵심

### 시뮬레이션

```text
내 위치 선택
+ 발화 위치 선택
→ 자동 시작
→ 기본 1초마다 연기값 갱신
→ TensorFlow.js 미래값 예측
→ A* 경로 재계산
→ 파란 대피 경로 실시간 변경
```

갱신 간격은 1초, 2초, 3초, 5초 중 선택할 수 있습니다.

## TensorFlow.js 작동 방식

페이지가 열리면 다음 순서로 실행됩니다.

1. `models/model_10s`, `model_20s`, `model_30s`의 학습 모델을 불러옵니다.
2. 학습 모델이 정상적으로 로드되면 `5단계 학습 모델`로 표시합니다.
3. 모델 파일이 없거나 오류가 나면 TensorFlow.js로 `내장 시연 모델`을 생성합니다.
4. 페이지 시작 시 자동으로 세 모델에 시험 입력을 넣어 검증합니다.
5. 시뮬레이션 매 갱신마다 `predict()`를 다시 실행합니다.

따라서 AI 진단에서 다음을 확인할 수 있습니다.

```text
모델 종류
TensorFlow.js 버전
검증 결과
추론 횟수
마지막 추론 시각
현재값과 30초 예측값의 최대 차이
```

### AI 모델 검증 실행 버튼

이 버튼은 언제든지 누를 수 있습니다.

- 페이지 시작 시에는 자동 검증
- 버튼을 누르면 수동 재검증
- 세 모델의 입력 30개와 출력 30개 확인
- 실제 `predict()` 실행 여부 확인

## 화면 개선

- 지도와 센서값을 좌우로 배치
- 위험도 30개를 작은 카드로 표시
- AI 진단 정보를 한 영역에 압축
- 네 시간대의 경로를 지도 바로 아래 표시
- 화면의 세로 길이를 줄임

## ESP32 실제 구현 탭

실제 구현 탭은 다음 센서를 표시합니다.

```text
A1~A4: 알코올 감지 센서 4개
F1: 불꽃 감지 센서 1개
```

6단계 Apps Script의 `/exec` 주소를 입력하면 최신값을 가져옵니다.

## GitHub 업로드

압축을 풀고 폴더 안의 다음 항목을 저장소 최상위에 모두 올립니다.

```text
index.html
css/
js/
assets/
models/
README_학생용.md
```

학습 모델을 사용하려면 5단계 결과를 `models` 폴더 안에 복사합니다.

```text
models/model_10s/model.json
models/model_10s/*.bin
models/model_20s/model.json
models/model_20s/*.bin
models/model_30s/model.json
models/model_30s/*.bin
```

모델을 넣지 않아도 내장 시연 모델로 TensorFlow.js 실행 여부를 확인할 수 있습니다.


## ESP32 실제 구현 탭 대피 경로 기능

실제 구현 탭에서도 시뮬레이션과 같은 방식으로 대피 경로를 안내합니다.

```text
맵 1 ↔ 알코올 센서 A1
맵 2 ↔ 알코올 센서 A2
맵 3 ↔ 알코올 센서 A3
맵 4 ↔ 알코올 센서 A4
```

작동 순서:

```text
Apps Script에서 A1~A4 수신
→ TensorFlow.js 4입력 모델 실행
→ 현재·10초·20초·30초 위험도 생성
→ 실제 구현용 복도 그래프에 위험도 적용
→ 출구 1·2·3 중 안전한 출구 선택
→ 실제 맵에 파란 대피 경로 표시
```

### 내 위치 선택

1. `내 위치 선택` 버튼을 누릅니다.
2. 실제 구현 맵의 1~4 중 현재 위치를 클릭합니다.
3. 파란 위치 핀이 표시됩니다.
4. 센서값을 새로 받을 때마다 경로가 다시 계산됩니다.

### 불꽃 센서 F1과 최초 알코올 감지 위치

실제 구현 탭은 다음 순서로 발화 위치를 정합니다.

```text
F1 미감지
→ F1 감지 시작
→ 감지 직전 A1~A4 값을 기준값으로 저장
→ A1~A4의 상승을 1초마다 추적
→ 가장 먼저 기준을 넘은 센서를 최초 연기 감지 위치로 기록
→ 해당 맵 위치에 불꽃 표시
→ 다른 센서값이 더 높아져도 위치 유지
→ F1이 미감지로 돌아오면 기록 초기화
```

기본 감지 기준:

```text
알코올 위험도 20 이상
기준값보다 5 이상 상승 또는 직전 값보다 3 이상 상승
강한 반응값 35 이상은 즉시 감지
```

같은 1초 안에 여러 센서가 함께 반응하면 다음 순서로 결정합니다.

```text
1순위: 직전 값보다 증가 폭이 큰 센서
2순위: F1 감지 직전 기준값보다 증가 폭이 큰 센서
3순위: 현재값이 큰 센서
4순위: A1 → A2 → A3 → A4
```

불꽃 위치가 정해진 뒤에는 해당 위치를 연기 발생 지점으로 사용하여 현재·10초·20초·30초 위험도를 계산하고 대피 경로를 다시 안내합니다.

### 실제 구현 TensorFlow 모델

실제 구현 탭은 기존 30입력 모델을 직접 사용하지 않습니다.  
A1~A4에 맞는 4입력 TensorFlow.js 확산 추정 모델을 사용합니다.

```text
입력: A1, A2, A3, A4
출력: 10초·20초·30초 뒤 A1, A2, A3, A4
```

이는 실제 탭에서 TensorFlow.js `predict()`를 실행하기 위한 모델입니다.
